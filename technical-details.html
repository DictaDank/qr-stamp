🏗️ Arquitectura

Stack Tecnológico

Frontend: Vanilla JavaScript (ES6+) Build Tool: Vite 8.2.0 PDF Processing: PDF.js + pdf-lib QR Generation: qrcode 1.5.4 Cryptography: node-forge + jsrsasign Certificates: pkijs + asn1js Bundler: Rolldown (Vite) Styling: CSS3 + CSS Variables

Estructura de Archivos

src/ ├── main.js (línea maestra) ├── style.css (estilos) ├── certificate-ui.js (interfaz certificados) └── security/ ├── certificates.js (gestión de certificados) └── digital-signature.js (firma digital) public/ ├── favicon.svg ├── icons.svg └── sample.pdf dist/ └── (build producción)

Flujo de Datos

Usuario carga PDF ↓ [8 Validaciones] ↓ Carga en memoria (pdfjs) ↓ Usuario agrega sello ↓ [5 Validaciones] ↓ Usuario procesa ↓ [Firma Digital Optional] ↓ Descarga PDF procesado ↓ Limpiar datos de memoria
